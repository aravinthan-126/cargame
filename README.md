# 🚗 Car Racing Game

A simple and interactive **Car Racing Game** developed using **HTML, CSS, and JavaScript**. This browser-based game allows players to control a car, avoid obstacles, and increase their score through real-time gameplay.

🌐 Live Demo:
https://aravinthan-126.github.io/cargame/

## 🎮 About The Project

Car Racing Game is a lightweight web game created to understand and implement front-end development concepts. The project focuses on game design, animations, keyboard controls, and JavaScript-based game logic.

The player controls a car on a moving road while avoiding incoming obstacles. The goal is to survive longer and achieve a higher score.

## ✨ Features

- 🚘 Player car movement using keyboard controls
- 🛣️ Animated moving road
- 🚧 Obstacle avoidance gameplay
- 💯 Score tracking system
- ⚡ Real-time game interaction
- 🎨 Simple and attractive UI design
- 💻 Runs directly in a web browser
- 📱 Responsive game layout

## 🛠️ Technologies Used

- HTML5 - Structure of the game
- CSS3 - Styling, animations, and layout design
- JavaScript - Game logic, movement, collision detection, and scoring

## 🎮 Controls

| Keyboard Key | Action |
|--------------|--------|
| Left Arrow | Move car left |
| Right Arrow | Move car right |
| Up Arrow | Control movement |
| Down Arrow | Control movement |
